# DEZZ1RE STUDIO audio files

## Beat previews (MP3)

The catalog in `index.html` uses the exact MP3 filenames stored in this folder. Keep each filename unchanged when adding or renaming a file, and update the matching `audio` value in the catalog. Beat titles displayed on the website should be uppercase, while audio filenames may use any case.

## WAV masters

Do **not** put full WAV masters in this public folder if you intend to sell them. Files placed in a public GitHub repository can be accessed by anyone. Keep WAV masters private and deliver them manually to the buyer after agreeing on the price and license through Instagram Direct.

## Upload from a phone

1. Export an MP3 preview from your DAW.
2. In the GitHub repository, open the `audio` folder.
3. Choose **Add file → Upload files** and select the MP3.
4. Commit the change to `main`.
5. Make sure the filename in `index.html` matches the uploaded file exactly, including spaces, punctuation, and letter case.
6. Wait for GitHub Pages to publish, then test the Preview button.
