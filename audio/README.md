# DEZZ1RE STUDIO audio files

## Preview files (MP3)

The website expects one MP3 preview for each beat in this folder:

- `redline.mp3`
- `no-signal.mp3`
- `crash-test.mp3`
- `afterhours.mp3`
- `bad-habit.mp3`
- `ghost-mode.mp3`

Names must be lowercase, with spaces replaced by hyphens. Use short preview exports rather than full untagged masters. The website will show an “audio not uploaded yet” message until the matching file exists.

## WAV masters

Do **not** put full WAV masters in this public folder if you intend to sell them. Files placed in a public GitHub repository can be accessed by anyone. Keep WAV masters private and deliver them manually to the buyer after agreeing on the price and license through Instagram Direct.

## Upload from a phone

1. Export a short MP3 preview from your DAW.
2. In the GitHub repository, open the `audio` folder.
3. Choose **Add file → Upload files** and select the MP3.
4. Commit the change to `main`.
5. Wait for GitHub Pages to publish, then test the Preview button.

For example, REDLINE must be stored as `audio/redline.mp3`.
